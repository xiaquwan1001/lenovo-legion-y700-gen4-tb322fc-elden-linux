## 刷机操作偏好
- fastboot/EDL 类断联场景：用户偏好**亲自执行命令**、助手只做分析（避开工具断联）。
- 复杂刷写/GUI 工具（如 LTBox）：用户亲自操作，助手准备资产并给精确步骤。
- 动手前先确认不破坏当前可用系统。
- 长任务反复失败无进展时：先写复盘记录（操作史/根因/文件清单）再切换方案。
- 先查社区现成资源与本地已有等效资产，避免重复下载大文件。
