# T2-001 收益/成本 与 T5 中文输入 解释（2026-11-27 深夜，给用户决策）

## A. T2-001（WifiProvisioning 自愈，需重编 Android 镜像）—— 收益 vs 成本

**它修什么**：虚拟 Wi-Fi `"Droidloom"` 一旦某次 captive-portal 校验失败，`WifiConfigManager`
把它 **永久禁用并落盘**（`NETWORK_SELECTION_PERMANENTLY_DISABLED`）；`WifiProvisioning` 用一次性
`DONE` 位，**从此不再复查** ⇒ cell 跨重启一直没网，只能手工 `cmd wifi connect-network` 救回
（= droidloom issue #48 的根因 1）。修法（上游维护者分支 `gotakllc@4e995f2`，未进 main）= 去掉一次性位、
改成监听 `NETWORK_STATE_CHANGED/WIFI_STATE_CHANGED` 后 `enableNetwork(true)`。

**成本（来自 `docs/BUILDING.md` 实测口径）**：
- **磁盘**：`Allow 120 GiB free for a fresh build`（源码+工具链+编译缓存）。
  本机现况 = **937 G 盘 / 已用 607 G / 可用 283 G**（69%）⇒ **够，余量约 160 G**。但这是最大头，装完建议仍留 ≥100 G。
- **内存/CPU**：`32 GiB RAM + 16 逻辑 CPU` 级别（本机 28 线程、内存够）。
- **工具链**：要 **rootless Podman + Arch Linux 构建容器 + Arch ARM sysroot**（在 Debian 13 上跑 Arch 容器，
  不是原生组合，首次搭建有踩坑风险）；AOSP 首次全量编译 **数小时**。
- **性质**：这是 **Android systemui（Java）** 改动，必须重出 `image` 包才能生效，**不能像 002/003/004 那样只换二进制**。

**关键判断：它的收益大部分可被「宿主侧小 unit」以极低成本替代。**
001 要解决的「跨重启没网」= 两件事叠加：① SSID 被永久禁用不清除；② 没有开机自愈。
而我们已经有：003 已让 lease 带宿主 resolver（DNS 不再依赖 nft 重定向）。剩下的只是「SSID 被禁用后没网」。
一个**宿主 systemd oneshot unit**（开机 / 检测到 cell 无默认路由时）：`adb shell cmd wifi connect-network "Droidloom" open`
+ 设 `captive_portal_*_url`，即可覆盖 95% 使用场景，**无需 120 GiB 构建、无需碰 Android 镜像**。代价 = 仍是「本机规避」，
不上上游；且开机多几秒。

**建议**：**暂缓 001 的镜像重编**。理由 = 收益可被宿主 unit 更便宜地拿到；120 GiB + 数小时 + Arch 容器搭建的组合成本偏高，
且这是维护者自己尚未合并的分支（随时可能变）。**只有当你明确要「把这条修复做成可上游的、进 image 的正式件」时**才值得编。
若你同意，我可以先写那条宿主 unit（半天内、零大下载），把「跨重启没网」先根治到可用级。

## B. T5 中文输入 —— 到底是什么、为什么需要人

**现状（今晚实测）**：
- 系统默认真实 IME = **Fossify Keyboard**，它**没有中文布局**（只能英文/符号）。
- 我装了 **Trime（Rime 同文输入法）3.3.13 arm64**（`droidloomctl install` 成功，`ime list` 已注册、`ime set` 能切成默认）；它**能打中文**。
- **但** Trime 首次启动停在 **SetupActivity（一个向导页）**，且日志报 **`Skip starting rime: storage not available!`**
  —— 它的 Rime 词库/方案还没部署到它要的目录，所以现在切过去 = 一个「还没装载词库的空输入法」，打不出字。已恢复默认 Fossify、关掉 Trime，设备未留在坏状态。

**为什么需要人（而不是我全自动）**：
1. **SetupActivity 向导要点选**（选方案/授权存储），是图形交互，我能用触点注入但**需要你目视确认每步点对了**；
2. **`storage not available`** 这条要先定位 Trime 期望的词库目录（可能要把它指到 `/sdcard` 或内部 `files/`），
   属「配一次就知道」的探索，最好有人在旁边看着它到底卡哪一步；
3. **最根本的是取舍**：Android 同一时刻**只能有一个默认 IME**。要么 **Fossify（英文顺手、无中文）**，
   要么 **Trime（中文可用、但要装词库、英文体验不如 Fossify）**——**两者不能同时当默认**。这是你的偏好，得你定。

**我需要你回一句**：默认 IME 你要 **Fossify（维持现状，放弃中文）** 还是 **Trime（我把它词库部署好、切成默认、你来试打中文）**？
选了 Trime，我会约一个 10 分钟窗口：装词库 → 走完向导 → 切默认 → 你打「你好」验证 → 定稿。
