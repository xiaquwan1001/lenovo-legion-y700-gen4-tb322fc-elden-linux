## 2. 关键结论（含被证伪项）

### G1-34（加速度计/重力旋转）
- SM8750P **无独立 SLPI**，Sensor Core 在 ADSP；卡点是 ADSP fastrpc 节点缺 `qcom,non-secure-domain`（本树只加在 cdsp）→ `/dev/fastrpc-adsp` 不存在。
- 修后：`hexagonrpcd-adsp-sensorspd`（Alpine 包）+ HexagonFS 喂原厂配置 → svc 400 → 全传感器出数。
- **剩余**：Phosh 不自动旋转 —— iio-sensor-proxy 3.9 的 **SSC claim 竞态**（claim 发生在 driver open 嵌套主循环内、polling 未开 ⇒ orientation 冻结；重启 proxy 即恢复实时）。补丁已取到（1 hunk），重建方案已备（abuild、pkgrel bump、回退已记录）。**未做**：需要用户物理旋转观察做最终判定（Method B 闸门）→ 用户暂缓。

### Q28（面板 init 间歇失败 → 只有背光）
- **永久闩锁**：`dsi_bonded_cmd_failed`（`dsi_manager.c:41`）失败置位、全树无清除 ⇒ 之后所有 bonded 传输 `-EIO`（`cmd_xfer:674`）⇒ 面板 retry 必然 -5、本 boot 永无恢复。
- **候选补丁已实现**（`patches/q28-dsi-cmd-recover.patch`，基于 vk64 源 d02658e63）：`msm_dsi_host_reset()`（sw_reset+PHY reset）导出 + `cmd_xfer` 闩锁时有界（≤3 次）复位 master+slave 并清闩锁、成功清零计数。
- **实测（vk72-q28dsi2）**：✅ 恢复路径在跑（`bonded cmd failed; host/phy reset, retrying (1)(2)`）；✅ DRM 起来了（card0-DSI-1 connected，模块匹配修复后）；❌ 但 3 次重试仍全 -110 ⇒ **根因更深：首条 bonded 命令的 DMA 引擎根本没完成**（master/peer 同时超时；`status=0x2200200` 实为中断掩码寄存器、有误导性）。
- **强相关性**：冷启成功、`fastboot boot`/温重启失败（累积）；bootloader（ABL）遗留的 DSI/面板状态是主嫌。
- `DSI PLL lock failed`（boot 早期）是 dispcc orphan reparent 告警，非本次根因。
- **未竟**：寄存器级定位被 `CONFIG_STRICT_DEVMEM=y` 挡住（`/dev/mem` 读不了 DSI 寄存器、devmem 工具也不在）→ 需要**诊断内核**（在超时点 dump DSI_CTRL/RESET/CLK_CTRL/INTR_CTRL/CMD_DMA_CTRL）才能钉死「引擎为何不跑」。诊断代码**已设计未实现**（本轮收尾）。

### Q26（WiFi 到可用）
- 静态：vk62↔vk63 内核+ramdisk 逐字节相同、DTB 只差 cambist 且不含 WiFi ⇒ 回归在 **vk61→vk62 的内核+initramfs 更换**；待 `vk62` 单变量复核。

### Q24（熄屏×相机）
- 原厂证据削弱「改 MXC」假设（原厂 cambist 只用 `vdd_mx`）；备好 `vk71-mxc`/`vk71-mxnom` 待 ≥9 轮。

### 基础设施踩坑（本轮新增）
1. **`reboot2` 无参默认 `bootloader`** → 已修（`rootfs/reboot2.c`：无参=普通重启；显式传参才给 reason），aarch64 静态二进制 `out/reboot2-fixed` 待部署。
2. **面板失败态 `reboot -f` 会挂住**（DPU 卡死挡关机路径）→ 必须用 `echo b > /proc/sysrq-trigger`；连续热重启会**累积**面板失败，优先冷启。
3. **`pkill -f <模式>` 会匹配并杀掉执行命令的远程 shell 自身** → 用 `pkill -x`。
4. **pi-subagents `researcher` 的 tools 白名单**含本机不存在的扩展工具名 → 已在项目 `.pi/settings.json` 覆盖（数组形式）；web 工具仅后台子代理可加载。
5. **测试内核要能加载模块**：`uname` 必须精确匹配 `/lib/modules/<release>`；用 `CONFIG_LOCALVERSION` 硬编码 + `LOCALVERSION=`（空但已设置，避免 `+`）+ `CONFIG_LOCALVERSION_AUTO=n`。`.config` 改完要还原（本轮已还原：`-debug`/`AUTO=y`）。

### 🟡 Q28 显示间歇 —— 诊断推进 + 两假说降级 + 根因收窄（暂停，未推进硬件/构建）
