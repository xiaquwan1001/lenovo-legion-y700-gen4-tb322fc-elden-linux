| 后端 | model id（fabric 里可直接传） | 冒烟延迟 | 状态 |
|---|---|---|---|
| **DeepSeek 直连** | `deepseek/deepseek-chat` | **2.3 s**（裸 API 1.0 s） | ✅ 可用，**首选备用** |
| **USTC 直连** | `ustc/deepseek-flash` | **2.3 s**（裸 API 5.5 s） | ✅ 可用，第二备用 |
| **nexus 网关**（现默认） | `custom-nexavlinks-com/deepseek-v4.1-flash` | 2.3 s（短任务） | ⚠️ 长输出今日中断 4 次（L7/L1/L6/L9） |
| ustc-pool（litellm 池） | `ustc-pool/ustc-worker` | **30.6 s** | 慢，不作首选 |

**规则**
1. 默认仍走 nexus（项目口径）；**任何 lane 因 `Upstream response stream was interrupted` / `ClientPayloadError` 死亡 ⇒ 同一任务原样改传 `deepseek/deepseek-chat` 重派**，不再用 nexus 重试第三次。
2. deepseek 也失败 ⇒ `ustc/deepseek-flash`；第三顺位才是 nexus。
3. **长输出 lane（>10 KB 报告）直接派 deepseek**，不等失败再切。
4. ustc-pool 仅在直连两家都不可用时使用（TTFT 30 s 级，会撞恢复看门狗）。
5. 每条重派保持同一 task 文本 + 同一产物路径（续作判定不变），避免产物分叉。
