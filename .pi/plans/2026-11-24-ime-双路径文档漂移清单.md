# IME 双路径文档漂移清单（2026-11-24，只读审计 lane）

判据前提（今日设备实测，作为事实基线）：
1. 键盘唤不起的真根因 = `org.gnome.desktop.a11y.applications screen-keyboard-enabled` 为 **false**
   （osk-stub `set_surface_prop_surface_visible()` 无条件 `visible=FALSE`）；设 true 后 Firefox 地址栏聚焦
   ⇒ osk-stub 立即收到 `zwp_input_method_v2.activate` 并显示键盘（截图 `/tmp/s_ff5.png`）。
2. phoc **0.46 的 `handle_text_input_enable()` 无版本门**（门是 0.58+ 才有）；但 `relay->input_method == NULL`
   或 IM 槽被 fcitx5(`waylandim`) 抢走时，osk-stub 只印 `Input method unavailable` 且永不显示。
3. 现役中文路径 = phosh-osk-stub（divert+hold 自编件）+ RIME completer（`Completers default=rime`），
   候选在 OSK 自身 layer surface 内产生，**不需要 fcitx5**；fcitx5 / fcitx5-ime-toggle / fcitx5-indicator /
   `elden-ime-focusd` / squeekboard 属老路，应与新栈互斥（不应自启）。

- **涉及文件：20 个**（3 个 SSOT 文档 + 5 个 PITFALLS 会话文件 + 6 个脚本/清单 + 6 个报告）

  其余 3 条（a11y key / 老路件不自启 / `Input method unavailable`）只存在于**未纳管的新脚本** `scripts/ime-single-stack.sh`（未 git 纳入、全仓无指针）。**
