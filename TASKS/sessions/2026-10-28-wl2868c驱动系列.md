## 坑（本 lane 实测）

- **`scripts/dtc/dt-check-style` 必须用 `~/.local/opt/dtschema-venv/bin/python`**（系统 python3 缺 `ruamel.yaml`）；
  `make dt_binding_check` 里 `yamllint` 那步因未安装被 Makefile **静默跳过**（`warning: python package 'yamllint'
  not installed, skipping`）⇒ `dt_binding_check rc=0` **不等于** YAML 风格过关，必须单跑 `dt-check-style`。
- **`--mode=strict` 才有的 nit**：`yaml:74 [property-order]` —— example 里 `regulator-min-microvolt` 应在
  `regulator-max-microvolt` **之后**（字母序 max < min）。内核侧门禁是 relaxed 档（已 rc=0），**本轮刻意不修**：
  改 example 就要重生成 1/2，而 1/2 的 diff 段目前与**已投 v2 逐字节一致**（verbatim resend 的前提）。
- **`/tmp` 是 tmpfs**：上一轮 lane 建的 `/tmp/wl2868c-drv`、`/tmp/wl2868c-v2` 已被主机重启清空，
  `git worktree list` 只剩 `prunable` 条目；本 lane 先 `git worktree prune` 再从分支 `worktree add` 恢复
  （**分支与 commit 没丢**，丢的只是 checkout 目录）。
- **`linux/drivers/regulator/wl2868c-regulator.c`（140 行）是旧开发副本**，与投递用 0002（155 行）内容不同
