# 2026-10-28 · U2（B5/M6 原子回调时序）上机取证并关闭

- **日期**：2026-10-28
- **pi 会话 id**：`$PI_SESSION_ID`
- **主题**：`继续任务` 的第一优先项 —— `PROGRESS` §6 第 8 条里唯一「可纯自主推进」的 G1 项：
  B5 设计稿 §1 第 9 项 **U2「非原子回调 → 原子回调后的时序」**（静态判不了，需上机时间线）。
- **结论（数字）**
  - 现场时间线（`ftrace` function tracer，零写盘，2 轮 blank/wake）**8 项判据全 PASS**，两轮**逐项同序**：
    - **enable**：`dsi_mgr_bridge_pre_enable`（只 `msm_dsi_host_power_on` ×2）→ `drm_panel_prepare`
      → **219.4 / 222.6 / 224.2 ms**（面板 DCS 初始化）→ `drm_atomic_bridge_chain_enable` →
      `dsi_mgr_bridge_enable`（`msm_dsi_host_enable` ×2）→ `drm_panel_enable`。
    - **disable**：`drm_panel_disable` → `dsi_mgr_bridge_disable`（`msm_dsi_host_disable` ×2）→
      `drm_panel_unprepare` → `dsi_mgr_bridge_post_disable`（`msm_dsi_host_power_off` ×2 + `dsi_mgr_phy_disable`）→
      `drm_atomic_helper_commit_planes`。
  - ⇒ **现有 `.atomic_pre_enable/.atomic_enable/.atomic_disable/.atomic_post_disable` 的切分就是推荐形状，U2 不需要补丁**（从「待上机」转「已证」）。
  - 关键机理（上游要的那句）：`drm_atomic_helper_commit_modeset_enables()` 在**同一次提交**里先跑完
    `drm_atomic_bridge_chain_pre_enable()` 全套，再 `drm_atomic_bridge_chain_enable()` ⇒ 「面板就绪」是 enable 方向的硬闸门；
    因此 host link enable 只能在 `.atomic_enable`（此处 `panel->prepared` 必然为真），
    host disable 只能在 `.atomic_disable`（夹在 `panel_disable` 与 `panel_unprepare` 之间，关屏命令仍可下发）。
  - bonded 计数验证：桥回调 **1 次**（slave 桥按 `IS_MASTER_DSI_LINK` 早退）、host/power **各 2 次**、`phy_disable` **1 次**。
  - 回归面：`command DMA timeout` / `vblank timeout` / `reset failure` / `panel is not prepared` **全 0 → 0**；
    采集前后 `dpms=On enabled=enabled status=connected`，会话/phoc/phosh 不变，`systemctl --failed` 空。
- **新增可复跑判据**：`scripts/b5-u2-atomic-timeline.sh`（采 + 判 + artifacts 归档；`--no-capture` 只判；
