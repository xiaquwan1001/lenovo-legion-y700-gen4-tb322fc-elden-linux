  静态定案并造好下一发上机件
- **结论**：
  1. **p37 的「EB 之后立刻死」= 自家探针自杀（静态定案）**：`R32` 的 `SbDumpLogNoBs()` 仍用
     `AllocatePool`×2 / `FreePool`×2，`SbWriteLogWindowNoBs()` 又用一次；EB 后 `gBS` 已死，
     `gBS+0x40`（AllocatePool）取出 0 ⇒ `blr x8` 跳 `pc=0`，与屏上 `[K] FLT pc=00000000 esr=86000007` 同形。
     同函数还漏改一处 `Lba`（字节偏移当块号，`R32` 只修了 `SbWriteLogWindow`）。
  2. **`R33` 已落地并构建**：EB 后路径全改静态缓冲；新增 `[K] BL-in` / `BL-vm=` / `gbs=…`（EB 前）/
     `EBC-call` / `EBC-ret0|ret!`（EB 调用两侧，只写内存）/ `post gbs=…`（EB 后带 `cbz` 守卫的内存读）/
     `post-dump-ok`。镜像 `out/r21-sbstop-p38/uefi-preamble38-r1.img`（`0e2bddbd…272badad`，67 219 456 B）。
  3. **独立静态复核 PASS**（verify-worker 反汇编 + 编排者抽样复跑）：EB 调用 `0x5a9c bl 0x1630c`；
     其后到跳内核前 **0 处 boot service 调用**，唯一 gBS 触点是带 `cbz` 的内存读 `0x5b2c`；
     `SbDumpLogNoBs`（`0x47f4–0x49c8`）内池调用 0 处；镜像载荷与 `payload-v2aligned.bin.gz` 逐字节一致。
  4. **未上机**：设备当时未连接（`adb devices` 只有华为手机与模拟器；`192.168.7.2` 无路由）。
