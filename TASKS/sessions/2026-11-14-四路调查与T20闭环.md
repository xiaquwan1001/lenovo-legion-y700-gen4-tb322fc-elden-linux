## 2. T20 根因（逐环实证）

**`zwlr_output_power_v1` 每个 output 只允许一个请求者**（wlroots 语义）。会话启动时有两个客户端请求 DSI-1 的 power 对象：

```
polyw: get_output_power client=… pid=926212 (droidloom-wayland)  → send mode 1
polyw: get_output_power client=… pid=926242 (phosh)              → 旧代码 send_failed + 销毁服务端资源
```

phosh 的 `wlr_output_power_handle_failed()` 只打 warning ⇒ `PhoshMonitor.power_mode` 停在初始
`POWER_SAVE_MODE_OFF`（语义「屏已关」）⇒ `active = (mode == OFF)` 恒 TRUE ⇒
`on_power_button_pressed()` 的 press/release 两支全短路。**并且 proxy 已死**：按电源键时 phosh 自己日志有
`Entering power save mode: 1`，但 phoc 侧 0 行 `Request to set output power mode`、
`strace -e trace=ioctl` 45 s 内 **0 次 `DRM_IOCTL_MODE_ATOMIC`** ⇒ 请求从未到达合成器。
这解释了为什么「挂起能用（走 logind）、长按菜单能用、只有短按熄屏失效」。
