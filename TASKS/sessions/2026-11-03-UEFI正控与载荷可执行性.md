- 结论（先数字）：
  1. **DDR 黑匣子正控通过**：真内核 `primary_entry` 写四窗 → 断电重启读回 **95.2% / 97.3% / 97.2% / 97.8%** 字节为 0xFF ⇒ 通道成立，11-02 的 `stage1=0` 不是假阴性。
  2. **`usb_read failed` 不是交棒判据**（11-01 起用了 7 次）：自旋探针同样触发它，但四窗标记全 0。ABL 有两条结局：真内核 `Sending 1.4–1.9 s` + `Booting OKAY 10.106 s` + 真执行；我们的 UEFI 件 `0.056 s` 立刻拆 USB + 2 s 回落 Android = **早期拒绝**。
  3. **不存在 1–2 s 看门狗**：自旋载荷在 logo 上躺数分钟无人复位 ⇒ 旧「ABL 武装 wdog 无人喂」假设作废。
  4. 小裸件/小 gz 件 = `10.106 s` 后挂死 logo、标记 0（需要人工断电，且长时间卡 logo 会污染 carveout：曾读到整窗 95% 0xFF 的假标记）。
