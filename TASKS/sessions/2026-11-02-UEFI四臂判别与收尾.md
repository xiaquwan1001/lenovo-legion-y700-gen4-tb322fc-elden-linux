## 1. 结论（先数字）

1. **UEFI ①「EDL 直读 DDR」作废**：本机 loader `xbl_s_devprg_ns.melf` 的 Supported Functions 无 `peek`；`rawxml` 手发 `<peek>` 两发空回包 ⇒ 不可用（`PITFALLS #486`）。
2. **三块 carveout 窗口在整条启动链里不被写**：`0x84A00000`/`0x9C300000`/`0x89300000` 清零后走完「载荷→fastboot→flash→Linux」整圈仍逐页 0 ⇒ 「回落覆盖」假设作废（0x00 是稳定态）。
3. **载荷在 slot 路径上 4 个变体全部 `stage1=0`**：A1（标记页 `dc civac` 回写）、A2（标记改 System RAM `0xE3F00000`/`0xC2500000`）、
   A3（A2 + `--ramdisk` 92 B + `--cmdline`）——**载荷第一条指令都没执行**。
4. **正控通过**：`a` unbootable + `boot_b`=日常 Linux ⇒ `sysrq-b` **3 s 回 Linux** ⇒ 切断动作本身不阻塞槽位启动。
5. **更正一条错判**：A3 期间以为「设备挂死 = 载荷被执行」，用户实测**正常进 Android**；`17ef:7f3d` = Android MTP。
   真因 = **ABL 自己把活动槽切到 a 并清掉 unbootable**，再正常起 Android（`PITFALLS #487` 追加条）。
6. **并行 lane**：C（10-05 出字配方 × 干净 v0 header）交付镜像 `out/uefi-20261101-1005recipe-v0.img`（sha `97c95cc1…`，0E/620W 零增量）；
   D（EUD）结论 = 本机 `eud` **0 次 probe**（运行 DT 无节点），XBL 初始化 10/10 但 `EUD wait` 0/10；B（合体 BOOT）**中止**（9 轮 12 调用 0 字），SunUEFI clone 已搬到 `~/ext-repos/sunuefi`。
