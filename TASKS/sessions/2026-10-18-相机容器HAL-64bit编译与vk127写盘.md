## 1. 关键判据与坑

1. **AVB 私钥 `bootslot-b/avb.key` 随换机丢失**：`vbmeta_b` 是 flags=3（verification+hashtree 全关）+ chain 指向旧 key `fc1e3b33…`。实测**重新生成一把 RSA-4096 key 自签 boot 即可被 ABL 接受**（unlocked/orange）。旧 key 无法复现，回退靠 `backup/HA2EXB0E-16+512/boot_b-m1-baseline-f3-20261017.img`（已签好的完整 96 MiB 镜像）。
2. **`tools/avbtool.py` 也丢了**：从 `android.googlesource.com/platform/external/avb/+/refs/heads/main/avbtool.py?format=TEXT` 取回（注意 main 分支文件名带 `.py`）。`generate_key` 子命令在 main 版没有 ⇒ 用 `openssl genrsa` + `openssl rsa -traditional`（PKCS#1）。
3. **`vendor.img` 是 inode 饥饿**：#244 记的「100% 满」真正卡的是 **inode**（`write: Could not allocate inode`），`resize2fs` 不会加 inode。正解 = `debugfs rdump` 出整棵树 → 补文件 → `mke2fs -N 8192 -d stage` 重建 → `debugfs sif` 补回 `0:2000`。
4. **passthrough HAL 查找只认 `<pkg>@<ver>-impl*.so`**（`system/libhidl/transport/ServiceManagement.cpp:openLibs`，`prefix = packageAndVersion + "-impl"`），**不看 `-external.so`**；AOSP 把 `HIDL_FETCH_ICameraProvider` 放在 `@2.4-impl.so`（`CameraProvider_2_4.cpp`，内部按实例名 `external/0` 分派）。只编 external 插件时必须自己导出该符号（`dl-cam/external-fetch-shim.cpp`）并**以 `-impl.so` 名字安装**。
5. **vendor 二进制的 linker 命名空间看不到 `/system/lib64`**：camera 系列 HIDL 库必须复制进 `/vendor/lib64`（否则 `CANNOT LINK EXECUTABLE ... library "android.hardware.camera.common@1.0.so" not found`）。
6. **`NDK + 平台库必须用同一个 libc++ 命名空间**：平台 libc++ 是 `std::__1`，NDK 默认 `std::__ndk1` ⇒ 编译加 `-D_LIBCPP_ABI_NAMESPACE=__1` 并链平台 `libc++.so`。
7. **本机 Waydroid 1.6.2 的容器管理器**：openrc 服务传 `-p <pidfile>`，而该版本 `waydroid` 已无 `-p` ⇒ 服务起完即死；**手动 `setsid waydroid container start` 才提供 dbus `id.waydro.ContainerManager`**。另外 root 起 session 会被 `XDG_RUNTIME_DIR=/run/user/1000` 所有权挡住 ⇒ 有桌面时用 uid 1000、无桌面时用 headless weston（需 `apk add weston-backend-headless`，USTC 镜像 DNS 首次会 transient error，重试即可）。
8. **Q28 坏发成簇**：8 连发里前 7 坏、第 8 好；坏发期间 `dmesg` 被 DPU `frame done timeout`/`vblank timeout -110` 刷屏，`grep -c "Failed to initialize panel"` 会被挤出缓冲区 ⇒ 判 Q28 要**开机 30 s 内**看。
