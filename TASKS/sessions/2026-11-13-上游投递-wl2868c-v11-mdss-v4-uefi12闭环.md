## 1. wl2868c v11（regulator，Mark Brown）

- Mark 的三选一：覆盖 LDOx_SEQ 还是非零时隐藏 enable/disable ops。取第一条。
- 依据 = datasheet **WL2868C Rev 1.4 p.35**：`0x0A..0x0D = LDOx_SEQ[3:0]`，`0000`（复位值）= 由 `0x0E`
  的 LDOx_EN 控制；`x001..x111` = 由 sequencer 的 slot 控制，此时写 LDOx_EN 无效。
- 板上只读实测（vk189 线，regmap debugfs）：`0x0a..0x0d = 00 00 00 00`、`0x0e = 0x80`、`0x0f = 0x00`
  ⇒ 本板固件未启用 sequencer，清零是 no-op；有 firmware 编程过的板子才需要它。
- 代码 = probe 里加 8 行（宏 + `regmap_bulk_write()` 清零），放在读 `0x0E` 播种之前。
- lore：三封均已归档；1/2、2/2 raw 在 pristine `git am` 后与源树 5 个文件 blob 全 SAME。

## 2. mdss（Dmitry 三问 + v4）

- 三问答案要点：① MDSS 在 DT 里就是 interrupt controller（`interrupts-extended = <&mdss 0>`），
  INT2 是同一块里的第二中断块（`MDSS_INT2_GDSC` + `DISP_CC_MDSS_CORE_INT2_BCR` 0xa000）；
  ② `msm_mdss_reset()`(msm_mdss.c:372) 早于 irq domain(:417) 与 `of_platform_populate()`(:537)，
  20 ms 保持沿用，不碰 PLL/时钟；③ 实测 = 三枚 bulk 形态 5/5 POR + 2/2 暖复位；未测 v4 形状、
  未做 INT2 单变量 A/B。
- v4 = 只重写 3/3 commit message，去掉「INT2 未复位 ⇒ command DMA timeout」的因果声称；
  带上 Abel(11-02) 与 Dmitry(11-11) 两个 R-b。diff 与 v3 逐字节相同（除 message）。

## 3. UEFI issue #12 闭环

- 10-29 已发过 0x402 反汇编结论（comment 6487769609，草稿文件状态未更新）。
