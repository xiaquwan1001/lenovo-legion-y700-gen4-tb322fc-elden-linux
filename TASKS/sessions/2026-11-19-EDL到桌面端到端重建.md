## 五个静默失败（已进 `PITFALLS` #681–#685）

1. **minbase 根缺 `udev`** ⇒ 模块零自动加载 ⇒ DP 组件 defer 拖死 DPU 聚合 = 只有背光（11-19 下午已修，本轮复述入口）。
2. **phosh 会话必需 `sm.puri.OSK0`**（Debian 包 `phosh-osk-stub`）⇒ 缺它 `gnome-session-failed` + 黑底转圈。
3. **Debian trixie Mesa 25.0.7 的 freedreno 不认 Adreno 830** ⇒ phoc GL 起不来、greetd `start-limit-hit`；
   处置 = pixman 开关或 trixie-backports Mesa 26.1.6（推荐）。
4. **RTC 写不了且冷起给「镜像构建日」2026-04-13（不是 1970）** ⇒ 日期阈值判据失效（本轮踩到），
   判据必须用 `chronyd -q` 退出码；且开机时无路由会让首次 time-sync 永久失败 ⇒ 路由就位后补跑 + 12×20 s 重试 + HTTP `Date` 兜底。
5. **usb0 只有地址没有默认网关**，且主机侧 `ip addr add` 随 gadget 重建消失 ⇒ 设备侧常驻自愈循环
   （`usb0-host-route.service`，15 s 一轮、宿主可达才补）。

## 遗留 / 下一步

1. **解锁需人手滑屏**：内核未开 `CONFIG_INPUT_UINPUT`（无 `/dev/uinput`），agent 无法注入触摸 ⇒ 桌面内容验证停在锁屏层。
   要自动化 UI 验证，需在 `patches/` 加 `CONFIG_INPUT_UINPUT=y` 并重打内核（另一条 cohort）。
2. 桌面已起但**未做桌面内实测**（浏览器/输入法/音频/亮度/Waydroid）：属于 G1-37/G2 面，逐项上机。
3. `phosh` 版本 = Debian 0.46（不是先前 0.59/stevia 线）⇒ `G1-38` 的 OSK 结论/`focusd` 桥在新栈上**未复验**。
4. 安卓面（a 槽卡 ZUXOS 动画）未动；`super` 与安卓分区本轮零改动。
5. Mesa 走的是 backports 26.1.6（不是自建 `/opt/mesa-a830`）⇒ 若要回「自建 Mesa」路线，需重做 `verify-image.sh` 那套链接。
