## 3. 为什么先修宿主机构建环境

重建 vk64 时的实际阻塞**不是配方**，而是：内核树里多个 tracked 文件被**单字符改写**（size/mtime 不变、`git status` 干净），
导致交叉编译随机 ICE/段错误、`ld` 报 `bad reloc symbol index`。详见 `reports/host-file-corruption-20261020.md`。

要点（已进 `PITFALLS` #282–#285）：
- git 不校验工作树内容 ⇒ 只能逐文件 sha1；
- `git checkout -f --` 对已损坏文件**可能无效**，治损坏用 `git cat-file -p HEAD:<path> > <path>`；
- `gcc -O0` 能过而 `-O≥1` 崩时，判序 = hello 探针 → 包完整性 → 输入文件 sha → 最后才怀疑源码；
- `ld` 指名的坏 `.o` 删掉串行重编即可，但要**迭代到收敛**（破坏会持续产生新的）。
