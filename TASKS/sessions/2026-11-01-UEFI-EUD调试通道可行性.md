## 结论（数字先，详见报告 §0）

1. **DT 缺 1 个节点 = 0 次 probe**：内核 `CONFIG_USB_QCOM_EUD=m`、`qcom_eud.ko` 在，但 `dmesg`/`lsmod`/`/sys/.../*eud*` 三处全空，
   运行 DT 里 `eud` 出现 **0 次**（`live-fdt.dtb` 154 766 B，`grep -ci eud` = 0）。
2. **vendor DT（同 SoC SunP）里 EUD 是好的**：`qcom,msm-eud@88e0000`、`status="ok"`、`reg=<0x88e0000 0x2000 0x88e2000 0x1000>`、
   `qcom,secure-eud-en`、`eud-utmi-delay=[00 ff]`（dtb 反编译 6476–6487 行）；另有 coresight `dummy-eud` sink（trace 通道）。
3. **XBL 有 EUD 代码、每次启动都跑**：`xbl_a.bin` 含 `boot_eud.c`/`EUD Init`/`EUD Post PMIC Init`/`EUD wait %ds`/`qusb_dci_eud_init`；
   `logfs` 10 段里 `EUD Post PMIC Init` 10/10、`qusb_dci_eud_init` 10/10、`EUD Init` 10/10、`usb_eud_serial` 10/10，
   **但 `EUD wait` 0/10** ⇒ 「bootloader 等调试器」未被证实。
4. **ABL/Mu-UEFI 完全不碰 EUD**（`abl_a.bin`、`uefi_a.bin` 的 eud 字符串命中 0）⇒ 若 XBL 不放行，就只能在 Linux/自研 UEFI 里开。
5. **工具链现成**：`quic/eud`（GPL-2.0/BSD-3）+ OpenOCD 上游 `eud` adapter（openocd.org 手册已列，对应 gerrit 9773）+
   `linux-msm/openocd` 的 `eud-rebased` 分支（`--enable-eud`，qcs6490.cfg 自称不绑定 SoC）。
6. **官方只承诺「Linux 起来后」**：Qualcomm 80-70029-12 明写「boot 期不支持，需 console/adb 手动 enable」「每次重启都要重开」，
   且只支持 QCS6490/IQ-9100/9075；使能路径 `echo 1 > /sys/bus/platform/devices/88e0000.eud/enable`（base 与我们相同）。
7. **三个缺口（不是三个开关）**：① DT 节点；② SM8750 的 m31 eusb2 PHY EUD 路由（`eud_enable_reg`=0x88e2000 4 B / `eud_detect_reg`=0xc278000）
   主线 PHY 驱动 0 实现；③ 使能末尾要 `qcom_scm_io_writel(0x88e2000,1)`，本机 SCM 是否放行未证。
8. **结论**：EUD 不能替代 DDR 黑匣子回答「载荷死在哪」；先做 0 成本 L0（PC 上 `lsusb` 看 `05c6:9500/9501`）。

## 下一步（建议，均需用户在场）

1. **L0（0 成本）**：设备接 Linux PC，冷启动，`lsusb` 看 10 s 内是否出现 `05c6:9500/9501` 或 7 口 hub。
   - 出现 ⇒ XBL 已 arm EUD，值得投 L1；不出现 ⇒ EUD 只在 Linux/UEFI 期可用，早期观测回到 DDR 黑匣子。
2. L1（~0.5 人日）：补 DT `qcom,eud@88e0000`（ports 接 dwc3 role switch）→ `insmod` → `echo 1 > …/enable`
   → PC `lsusb` → OpenOCD `eud.cfg` + `qcs6490.cfg`。判据链：probe ok → enable=1 → 9500/9501 → `SWD DPIDR 0x5ba02477`。
3. L2（+0.5 人日，仅当 L1 无 9500/9501）：照 vendor `phy-msm-m31-eusb2.c` 给主线 m31 PHY 补 `eud_enable_reg`/`eud_detect_reg`。
4. 风险提示：EUD 使能会关 USB host mode/adb（我们的 ssh 也在这根线上）⇒ 先备 WiFi/串口；`echo 0`/重启可回退。
