# 2026-10-29 非持久启动（kexec / fastboot boot）后设备从 USB 总线消失

- **pi 会话 id**：`01a18576-f4bd-752d-bd55-ffff5dba9473`
- **现象**：两种非持久启动方式结果一致 —— 目标"Booting OKAY"，随后主机 `lsusb` **无任何平板描述符**
  （无 `05c6/18d1/1d6b:0104`），`192.168.7.1` ping/ssh 全超时；主机侧只剩华为手机 tethering
  （`192.168.42.97/24`，网关 `192.168.42.129` = 手机 MAC `16:fd:f8:3a:d0:e8`）。
- **两次尝试**：
  | 方式 | 结果 |
  |---|---|
  | `kexec-boot.sh`（mask=1，继承 dwc3） | 无 USB（符合 `PITFALLS #378b`：目标继承 dwc3 活态 ⇒ 无网络） |
  | `fastboot boot out/boot-elden-camssv3.img`（cmdline 无 `androidboot.mode`） | 12 s "Booting OKAY"，同样无 USB；**超出 #378b 的解释范围** |
- **未证实**：目标内核是否真的起来（无网无法取 dmesg）；也没启用 `kexec_marker=1` 写盘取证。
- **待试（已备件）**：`out/boot-elden-camssv3cm.img`（cmdline 追加 `androidboot.mode=charger`，
  sha256 `a3c24221…`）—— 目的是复刻**已知可用**启动（slot b 那次 `/proc/cmdline` 就带该参数）的
  USB 配置环境。若仍无 USB，则改用「在持久槽做一次性刷写 + 复验」，不再走非持久臂。
- **恢复路径**：物理断电 → fastboot（用户已做过一次）→ `fastboot reboot`（回 slot b，持久 vk172）。
