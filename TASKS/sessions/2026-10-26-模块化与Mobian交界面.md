# 2026-10-26（续）· 驱动模块化 × Alpine→Mobian：交界面核对与落点改判

- **日期**：2026-10-26
- **pi 会话 id**：见 `$PI_SESSION_ID`
- **主题**：用户提问「考虑驱动模块化以及从 alpine 到 mobian 的迁移」。本轮只做**交界面核对**（主机侧 + 设备只读），
  不启动任何迁移落地、不写任何分区。
- **结论（4 条）**：
  1. **落点改判（最关键）**：f2fs 并存后已有两块 96 GiB ⇒ Debian 装 **`linux17` ext4**，Alpine 留 `linux18` f2fs 不动。
     迁移方案 §3.3 的「原地覆盖 rootfs + 无 live 回退（R2）」**作废**；回退 = 重启回 `boot_b`（秒级）。
  2. **换根必须换 boot 镜像**（根由 cmdline `elden_root=LABEL=` 决定，烧在 boot.img 里）⇒ S7 = 一条 `fastboot boot`（零写盘），
     不碰 AVB / 不写槽 / 不依赖 qbootctl。
  3. **两个工作量减免**：S4 可免 root（`depmod -b` 实测 rc=0）；`/init` 保留为 pre-systemd lifeline
     （Debian `busybox 1.38.0` 的 10 个必需 applet **全命中**）⇒ 省掉一半 systemd unit 改写。
  4. **抓到 1 个真实门禁缺口 + 1 个物料缺口**：apt-list 的依赖闭包缺 7 个包；传感器 DSP 目录
     `/usr/share/qcom/sm8750/LENOVO/TB322FC`（550 KB）不在 `elden-firmware` 包的 `/lib/firmware` 内。
- **证据指针**：
  - 报告（权威）`reports/modular-mobian-transition-20261026.md`（§0 三条改判 / §3 四个交界面 / §6 M1–M7 执行序）
  - 迁移方案已就地更新：`reports/mobian-migration-plan-20261021.md` §4 状态块（S3 改黄、S4 加 `depmod -b`、新增落点改判段）
