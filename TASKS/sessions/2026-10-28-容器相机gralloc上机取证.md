# 2026-10-28 容器相机 gralloc 崩溃上机取证（lane L1c）

- **日期**：2026-10-28（设备侧实测 21:40–22:20，容器本地时间 22:00–22:18）
- **pi 会话 id**：lane L1c（父会话派工单「容器相机 gralloc 崩溃判别 + 修法」）
- **主题**：Waydroid 容器里 external camera HAL 的 `formatConvert → libyuv::I420Copy`
  `SIGSEGV/SEGV_ACCERR` 的 E1/E2 判别与最小修法
- **结论**：
  1. **A 链路已恢复并复现**：`/dev/video100`（81,0）+ `Number of camera devices: 1`，生产者 NV12 1280x720@30.5fps。
  2. **E2 成立（已证）**：`IMapper@4.0` 对 **YV12** 输出缓冲返回自相矛盾的 `PlaneLayouts`
     —— ALOGV 实测 `y_str 2048 / c_str 0 / c_step 1`，`cb == y`；同一函数对 NV12 缓冲输出完全自洽。
  3. **E1 被弱否证**：同进程、同 usage 族（含 `CPU_WRITE_* = 0x30`）NV12 路径连写数十次无 ACCERR。
  4. **修法**：HAL 侧布局自洽校验 + 按 `plane1.offset/height` 反推 stride 的 YV12 回退 +
     `formatConvert` 前置校验 → `patches-userland/camera-gralloc-20261028/`，**未编译未上机**。
