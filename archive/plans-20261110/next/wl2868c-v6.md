## 5. driver preset 位修复（步骤 5）

**改法**：`wl2868c_enable()` 不再 `regmap_update_bits`，改为**整字节写** + 驱动侧记账：

```c
struct wl2868c {
	struct regmap *regmap;
	unsigned int enabled;	/* 消费者已使能的 LDO 位（WL2868C_LDO_ENABLE 布局） */
	struct mutex lock;
};

static int wl2868c_enable(struct regulator_dev *rdev)
{
	...
	ldos = (chip->enabled | bits) & WL2868C_LDO_ENABLE_MASK;
	ret = regmap_write(chip->regmap, WL2868C_LDO_ENABLE, WL2868C_SYS_ENABLE | ldos);
	...
}
```

`disable` 同构：清自己那一位，仍在用就写 `SYS_EN | 剩余位`，最后一个关闭才写 0（清 SYS_EN）。
因为整字节写，**固件 preset 的其它 LDO 位在任何一次 enable/disable 后都会被清掉**，
SYS_EN 置位不再能顺带点亮别的 LDO——即「只保留自己那个 LDO 的位」。

**证据（非自报，`GATES.md` #4 / `gates.log` §4）**：

```
make O=/tmp/wlv6-out -j26 W=1 drivers/regulator/            # rc=0，0 warning
  CC [M]  drivers/regulator/wl2868c-regulator.o
make O=/tmp/wlv6-out -j26 W=1 drivers/regulator/wl2868c-regulator.o   # rc=0
```

**边界**：本改动只有编译 + 代码路径证据；preset 位的真实复位值、以及「SYS_EN 置位后其它 LDO 是否真的
不上电」**未上机验证**（任务禁碰设备）。
