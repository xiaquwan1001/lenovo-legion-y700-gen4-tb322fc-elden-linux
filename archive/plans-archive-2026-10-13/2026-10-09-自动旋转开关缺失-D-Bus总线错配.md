# 自动旋转开关缺失 / 方向锁死 —— 【根因修正 2026-10-09 晚】

> ⚠️ 本文最初的「主 gnome-settings-daemon 未运行 → orientation 插件缺席」根因 **已被设备二进制 + 源码证伪**，正文作废，保留仅作弯路记录。正确结论见下。

## 正确根因（设备实测确证）
1. **Phosh 原生实现自动旋转，不碰 gsd**。设备 `/usr/lib/libphosh-0.45.so.0` strings 含 `/net.hadess.SensorProxy`、`Rotation manager mode: %d, has-builtin: %d`、`Built-in monitor present: %d`、`Got no sensor-proxy, no automatic rotation`、`notify::has-accelerometer`、`notify::orientation-locked`、`orientation-lock`，调试域 `phosh-rotation-manager` / `sensor-proxy-manager`。rotation-manager 连**系统总线** `net.hadess.SensorProxy` 取 `AccelerometerOrientation`，经 phoc 设 transform，锁状态绑 gsettings `org.gnome.settings-daemon.peripherals.touchscreen:orientation-lock`。
2. **gsd 50 根本没有 orientation 组件**（上游 gnome-46/50 的 `all_plugins` 都不含 orientation，Alpine 无主 daemon 也无 gsd-orientation）。→ 补 gsd 路线 100% 死路。
3. **rotate tile 的 .ui 绑定（设备二进制内嵌，实测）**：旋转 `PhoshQuickSetting` 的 **`visible=1`（始终显示）**，只有 **`sensitive` 绑 `rotateinfo.present`**。所以 tile 一直在，只是 `present=false` 时被置灰 → 用户感知「没有能用的开关」。
4. `rotateinfo.present` = rotation-manager 进 `MODE_SENSOR`（需 `HasAccelerometer=true`）**且** 有可旋转内置 monitor（`has-builtin`）。

## 最可能真因（待一次会话重启取证钉死）
- **(A) 启动时序**：本会话 `phoc` 与 `sensorspd` 同秒(14:47:44)启动；iio-sensor-proxy 要等 svc400(adsp 起后数秒) 才 `HasAccelerometer=true`。G1-34 已知 iio 3.9「只查一次、30s 拿不到 registry 就放弃」⇒ 若开机时 proxy 早于 svc400，proxy 整轮不报加速度计 ⇒ phosh 停 `MODE_OFF` ⇒ tile 置灰、无旋转。现 `HasAccelerometer=true`（我 15:14 重启过 proxy），但 phosh 是 14:47 起的、且我已把 phosh 的原代理 stop 掉 → 现会话 phosh 视图已失同步。
- **(B) SSC claim 竞态**（G1-34）：即便进 SENSOR，`AccelerometerOrientation` 冻结 ⇒ 有 tile 也不转。修法 `ssc-claim-race.patch`。
- **(C) 无可旋转内置 monitor**（phoc/GDK 把 DSI 屏判成非 builtin）⇒ present=false ⇒ tile 灰。用 `Rotation manager mode/has-builtin` 日志区分。

## ✅ 已定根 + 已修复（2026-10-09 晚，用户实机确认会转）
根因=**启动时序**：iio-sensor-proxy 与 hexagonrpcd-adsp-sensorspd 同在 default runlevel 并行起，proxy 抢在 svc400 前起则整轮无加速度计→phosh MODE_OFF。现场 `rc-service iio-sensor-proxy restart`+重启 phosh 会话后实测拿起横过来**能转**。
持久修复已落：`/etc/init.d/iio-sensor-proxy` 加 `start_pre()` 等 svc400（封顶 60s）+ `after hexagonrpcd-adsp-sensorspd`（备份 `/etc/init.d/iio-sensor-proxy.bak-timing-*`）；仓库真源 `rootfs/persistent-overlay/iio-sensor-proxy.initd`（restore.sh 已接）。**待下次冷启最终验证**（不擅自冷启）。UI 补充：phosh 无独立“自动旋转”开关，只有“方向锁定”tile（自动旋转开着时不显示方向选择栏），属正常模型。

# （作废）根因：主 gnome-settings-daemon 未运行（orientation 插件缺席）

> 设备 U2 现役 vk64，phosh 0.55.0-r2 / phoc 0.55.1-r0 / gnome-settings-daemon 50.1-r0 / iio-sensor-proxy 3.9-r2。
> 探针脚本：`/tmp/probe-rot.sh`、`/tmp/probe-gsd.sh`（本地 `cat>...<<'SCRIPT'` + scp 运行，**勿用多行引号脚本经 ssh 单引号——会被远端 zsh 压平吞参数**）。

## 症状
重力感应**数据正常**（前一步已把 mount-matrix 修为 `-1,0,0;0,-1,0;0,0,1`，方向反 180° 已解决），但：
- 屏幕方向**固定**，不随姿态转；
- Phosh 快速设置里**没有**「自动旋转 / 旋转锁」开关。

## 根因链（实测证据，逐条）
1. **proxy 没问题**：系统总线 `net.hadess.SensorProxy` 在（pid，OpenRC 服务），`HasAccelerometer = true`。
   - 纠正：iio-sensor-proxy 这个 build **只连系统总线**（带 `DBUS_SESSION_BUS_ADDRESS` 跑仍不注册到会话总线）——这是 systemd/Alpine 常规，非 bug。早先「总线错配」假设**作废**。
2. **主 gsd 未运行**：`pgrep [g]nome-settings-daemon` → **NO_GSD_MAIN**；phoc 会话总线上**无任何** `org.gnome.SettingsDaemon.*` 名。
3. **为什么缺席**：`/usr/share/gnome-session/sessions/phosh.session` 的
   `RequiredComponents=org.gnome.SettingsDaemon.A11ySettings;...Color;...Sound;...Wwan;mobi.phosh.Shell;sm.puri.OSK0;`
   —— **没有 `...Orientation`**，且 `/etc/xdg/autostart` 里也**没有** `org.gnome.SettingsDaemon.Orientation.desktop`（有 Color/Keyboard/Sound… 独缺 Orientation）。
4. **gsd 50.1 架构**：phosh 用「拆分成独立 `gsd-*` helper」模型（gsd-sound/power/media-keys… 各自进程，已跑），**但 orientation 在 gsd 50 里仍是主 `gnome-settings-daemon` 的内置插件（libgsd.so）**，Alpine 未提供独立 `gsd-orientation` helper。→ 拆分包模型下，谁都不拉起主 gsd，orientation 插件永不激活。
5. Phosh 的自动旋转 tile 绑定 `org.gnome.SettingsDaemon.Orientation`（gsd orientation 插件拥有）；该接口缺席 → tile 不显示 + 方向锁死。`gsettings orientation-lock` 能读到 `false`（值存在但无人消费）。

## 待定的正确修法（子代理 research 中，父落地）
候选（按侵入度）：
- **A（首选）**：让主 `gnome-settings-daemon` 在会话内运行、但只激活 orientation 插件（避免与已跑的拆分包 helper 抢其它插件名）。需确认 Alpine gsd 50 是否有单插件/禁插件开关（`--disable-plugin`? gsettings `org.gnome.settings-daemon` plugin 屏蔽?），或用一个只含 orientation 的 `RequiredComponents` + `gnome-settings-daemon` 的 `--component` 机制。
- **B**：把完整主 gsd 加入 `RequiredComponents`（或补 `org.gnome.SettingsDaemon.Orientation.desktop` 自启），并从 RequiredComponents 摘掉与之冲突的拆分 helper。风险：双份插件进程冲突。
- **C**：phosh 0.55 是否有不依赖 gsd 的 orientation 路径 / mobian 补丁。
- 验收：会话总线出现 `org.gnome.SettingsDaemon.Orientation` → Phosh 快速设置出现自动旋转 tile → 打开后随姿态旋转、关掉后锁定。
- 持久化 + 回退：改动写进 `scripts/openrc-enable.sh` / 一个 setup 脚本；回退=还原 phosh.session / autostart。
