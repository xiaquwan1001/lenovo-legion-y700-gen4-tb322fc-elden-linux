# BOOTSLIM-2026-10-05：G1-30 = G1-29 路线 C（最小 initramfs → switch_root）

> 承接 `archive/topics/BOOTCHAIN-2026-10-05.md` §4 **路线 C**、`TASKS.md` **G1-30**。
> 本文是**过程证据 + 主机侧交付**，只增不改。**本 lane 未写设备。**

## 0. 结论

- **boot.img 体积卡死已可在主机侧解除**：改用 busybox 最小 initramfs（~1.1 MB）后，镜像 **101 MB → 21,782,528 B（20.8 MiB）**，远小于 `boot_b`（96 MiB）。
- 机制早已存在（`initramfs/init` 会解析 `elden_root=LABEL=linux17` 并 `switch_root`；`build-boot.sh` 支持 `RAMDISK_KIND=busybox`），**唯一缺环 = busybox 没有 `blkid` 小程序**，导致 LABEL 解析失败并回退纯 RAM。
- 修复：`initramfs/init` 的 LABEL/UUID 分支加 **`findfs` fallback**（busybox 自带 `findfs`）。
- ⚠️ **内核版本必须与磁盘 `/lib/modules` 对齐**：本次产出的镜像内核是 `7.2.0-debug-vk42-geb432f18a0d1`，而实机 `boot_b`/`/lib/modules` 是 `7.2.0-debug-g4c68eb5ed4e3-dirty`（另有 `gba28ec16f01f`）。**直接刷会模块失配**（相机/音频等全部加载失败）⇒ E5 前必须用**目标内核**重打。

## 1. 改动（本 lane）

| 文件 | 改动 |
|---|---|
| `initramfs/init` | LABEL/UUID 解析加 `findfs` fallback：`root_dev=$(blkid -L LABEL=x \|\| findfs LABEL=x)`。PARTLABEL 仍走 `blkid`（busybox `findfs` 不支持 PARTLABEL）。 |
| `scripts/build-boot-slim.sh` | 新增：`VERSION=vkNN-slim sh scripts/build-boot-slim.sh` —— 打最小镜像 + 检查 ≤`boot_b` 分区 + 打印 inspect 摘要 + 回退提示。**不含内核/模块重建**。 |

## 3. 为何这样能生效（机理）

1. `boot.img` 只装 **kernel(Image.gz) + 1.1 MB initramfs**；`/init` 在 initramfs 上运行。
2. `/init` 读到 cmdline `elden_root=LABEL=linux17` → `findfs LABEL=linux17` 取到 ext4 分区（`/dev/sda17`）。
3. `mount -t ext4 -o rw,noatime` → `mount --move /dev /proc /sys /run` → `exec switch_root /newroot /init`。
4. 之后 `on_initramfs=0`，磁盘根的 `/init` 接管：dbus/网络/充电监控/相机模块自动加载/`start-desktop.sh` 桌面。
5. 体积不再受限于磁盘根大小 ⇒ **G1-30 解卡**；且这条**不依赖任何 UEFI/GRUB 改动**。

## 4. E5 上机清单（交父 agent/用户排期；本 lane 未执行）

前提：先用**与磁盘模块同版本的内核**重打 slim 镜像（否则模块失配）。

```sh
# 0) 备份/回退基线（现 boot_b 内容 = vk46-dirty）
ls -l out/boot_b-vk49.img          # 回退镜像（sha256 87a1f8f2…）

# 1) 零写盘试（首选，不落盘）
fastboot boot out/boot-elden-<同版本>-slim.img
#    判据：起桌面；ssh 后 `findmnt /` = /dev/sda17；`uname -r` = 目标版本；
#          相机模块自动加载（dmesg/模块在），`cat /proc/cmdline` 有 elden_root=LABEL=linux17

# 2) 通过后写回（持久）
VERSION=<同版本>-slim sh scripts/build-boot-slim.sh
fastboot flash boot_b out/boot-elden-<同版本>-slim.img
```

**回退**：`fastboot flash boot_b out/boot_b-vk49.img`（或 `fastboot boot` 零写盘验证后再写）。

**风险**：低（无 GPT 改动、无 dtbo 改动；纯 boot 载荷）。**唯一硬前提 = 内核↔模块同版本。**
