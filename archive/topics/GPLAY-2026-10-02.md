## 2. 安装步骤（已执行，可复现）

### 2.1 主机侧：准备本地 OTA 源
```bash
cd ~/y700-elden
# 1) 下载好的 GAPPS zip 放到 ~/下载/（规范名），运行：
bash scripts/gapps-mirror-setup.sh 8800     # 算 sha256、软链、写 GAPPS.json
# 2) 起 OTA HTTP 服务（后台）
nohup python3 -m http.server 8800 --bind 0.0.0.0 --directory waydroid-ota &
```

### 2.2 设备侧：备份 → 停 → 重装 GAPPS → 重挂 Mesa
```bash
ssh root@192.168.7.1
BK=/root/wd/backup-20261002-gapps
mkdir -p $BK
cp -a /var/lib/waydroid/{waydroid.cfg,waydroid.prop,waydroid_base.prop} $BK/
cp -a /var/lib/waydroid/lxc/waydroid/{config_nodes,config_session} $BK/
cp -a /var/lib/waydroid/images/system.img $BK/system.img.vanilla.bak      # 1.6GB 快照
cp -a /var/lib/waydroid/images/vendor.img  $BK/vendor.img.bak

# 停会话/容器（phosh 会话 env）
export XDG_RUNTIME_DIR=/run/phosh WAYLAND_DISPLAY=wayland-0 DISPLAY=:0 \
  DBUS_SESSION_BUS_ADDRESS='unix:path=/tmp/dbus-<当前phosh的>,guid=<...>'
waydroid session stop; waydroid container stop

# 重装 GAPPS（走本地镜像，USB-NCM ~33MB/s）
waydroid init -f -s GAPPS \
  -c http://192.168.7.2:8800/system -v http://192.168.7.2:8800/vendor

# 重挂 Mesa 26.1.8 + allocator.rc（init -f 会重建 config_nodes，把这些清掉）
bash /root/wd/waydroid-mesa-swap.sh install /root/wd/mesa-new
grep -q allocator.rc /var/lib/waydroid/lxc/waydroid/config_nodes || \
  echo 'lxc.mount.entry = /root/wd/allocator.rc vendor/etc/init/android.hardware.graphics.allocator@4.0-service.minigbm_gbm_mesa.rc none bind,create=file 0 0' \
  >> /var/lib/waydroid/lxc/waydroid/config_nodes

# 清空容器 data（干净 GAPPS 首启）
rm -rf /root/.local/share/waydroid/data/*

# 重启容器（常驻 daemon）+ 会话
nohup waydroid container start > /root/wd/gapps-container.log 2>&1 &
sleep 3
nohup env XDG_RUNTIME_DIR=/run/phosh WAYLAND_DISPLAY=wayland-0 DISPLAY=:0 HOME=/root \
  DBUS_SESSION_BUS_ADDRESS='unix:path=/tmp/dbus-<...>,guid=<...>' \
  waydroid session start > /root/wd/gapps-session.log 2>&1 &
```

## 4. 设备认证方法（Play Protect / Play Integrity）

### 4.1 Play Store「未认证」→ GSF 注册（官方标准做法）
1. 容器联网后，首次打开 Play Store 会提示「此设备未通过 Play Protect 认证」。
2. 取 **GSF android_id**（联网后 GSF checkin 成功才会生成，见 §6）：
   ```bash
   waydroid shell -- sh -c "sqlite3 /data/data/com.google.android.gsf/databases/gservices.db 'select value from main where name=\"android_id\";'"
   ```
   （当前 gservices.db `main` 表只有 `digest`，因 checkin 未成功——见 §6。）
3. 用该 16 位十六进制 ID 到 **https://www.google.com/android/uncertified** 注册（需 Google 账号，每账号最多 100 台）。
4. 等几分钟 → `waydroid session stop` 重启 → Play Store 可正常登录/下载。

> 备选：`Settings.Secure.ANDROID_ID` 当前为 `572ffaee5a55078e`（本机已读，数据不再 wipe 就稳定）。
> 但官方文档用的是 GSF gservices.db 的 id，两者可能不同——以 GSF id 为准。

### 4.2 Play Integrity 的诚实结论
- **GSF 注册解决的是「Play Store 能用 / 不再弹未认证」**，这是 Waydroid 官方支持、可达成的目标。
- **Play Integrity `MEETS_DEVICE_INTEGRITY` / `STRONG` 判据在 Waydroid 上不可达**：需要 TEE 硬件密钥证明，
  而 Waydroid 容器没有可用的 TEE（无 Keymaster/attestation key）。`MEETS_BASIC_INTEGRITY` 理论上可通过
  伪造 `ro.product.*` / 指纹（`waydroid prop set` + PlayIntegrityFix 类）拿到，但只对不查强认证的 app 有效，
  且随时可能被 Google 吊销。**不建议投入**，除非有明确需要。

### 6.3 直达 Google —— 被墙 ⚠️（需代理）
- 即便设备 WiFi 恢复（中国移动/校园网），`android.googleapis.com` 直连仍被墙。
- 主机（5700g）有 Clash Verge Rev 代理 `127.0.0.1:7897`（`allow-lan` 关闭，只监听 127.0.0.1）。
- 主机直连 Google 超时、走代理正常（404=可达）。主机到 USTC 镜像直连 200。

### 6.4 需要用户拍板/参与的收尾项
按「投入/收益」排序：
1. **恢复设备 WiFi 上行**：把手机热点开回来（或连一个可上网的 WiFi）。
2. **给 Google 通路**（二选一）：
   - **a. 设备侧代理**：在设备（Alpine）上配一个走主机 Clash 的代理（需把 Clash `allow-lan` 打开或 socat 转发 7897 到 192.168.7.2），再让容器 `settings put global http_proxy 192.168.7.2:<port>`；
   - **b. 主机 NAT + TUN**：主机 `sudo sysctl ip_forward=1` + `iptables -t nat -A POSTROUTING -s 192.168.7.0/24 -j MASQUERADE` + Clash TUN 透明代理（需主机 sudo，我这边非交互 sudo 不可用）。
3. **注册 GSF id**：`§4.1` 的 id 到 google.com/android/uncertified 注册。
4. **登录**：设备 GUI 打开 Play Store，用你自己的 Google 账号登录（账号凭据由用户提供，助手不代登）。
