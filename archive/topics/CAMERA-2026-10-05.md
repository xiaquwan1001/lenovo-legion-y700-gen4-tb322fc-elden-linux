## 1. 根因（推翻旧"待下一轮大工程"判断）

旧结论把 `-32`（`Failed to start media pipeline`）归为"需手工配格式/使能链路+3A，属下一轮大工程"。
本轮定位：**纯粹是格式协商 + 链路使能**，与 3A/曝光/时钟/供电无关（sensor probe、时钟、供电均已正常）。

实机 `media-ctl -p` 取证（配置前）：
- 五个 csiphy、五个 csid、各 vfe_rdi pad 默认格式 = **`UYVY8_1X16/1920x1080`**（camss 驱动初值）；
- sensor 输出 pad 真实格式 = **`SRGGB10_1X10`（gc08a8）** / **`SGRBG10_1X10`（s5kjns）**；
- sensor→csiphy 链路是 `[ENABLED,IMMUTABLE]`（DT 固定），但 **csiphy→csid→vfe→video 链路默认 `[]`（未使能）**。

⇒ 格式不一致 + 链路未通，启动流即 `-32`。

## 2. 打通步骤（前摄，实机命令）

```sh
M="media-ctl -d /dev/media0"
$M --set-v4l2 '"gc08a8 12-0031":0[fmt:SRGGB10_1X10/3264x2448]'
$M --set-v4l2 '"msm_csiphy4":0[fmt:SRGGB10_1X10/3264x2448]'
$M --set-v4l2 '"msm_csiphy4":1[fmt:SRGGB10_1X10/3264x2448]'
$M --set-v4l2 '"msm_csid0":0[fmt:SRGGB10_1X10/3264x2448]'
$M --set-v4l2 '"msm_csid0":1[fmt:SRGGB10_1X10/3264x2448]'
$M --set-v4l2 '"msm_vfe0_rdi0":0[fmt:SRGGB10_1X10/3264x2448]'
$M --set-v4l2 '"msm_vfe0_rdi0":1[fmt:SRGGB10_1X10/3264x2448]'
$M -l '"msm_csiphy4":1->"msm_csid0":0[1]'
$M -l '"msm_csid0":1->"msm_vfe0_rdi0":0[1]'
v4l2-ctl -d /dev/video0 --set-fmt-video=width=3264,height=2448,pixelformat=pRAA
v4l2-ctl -d /dev/video0 --stream-mmap --stream-count=10     # -> <<<<<<<<<< rc=0
```

后摄同法，**改用独立 csid1/vfe1 通道**（csid0 被前摄占用时报 `Unable to parse link: Resource busy (16)`）：
`csiphy3 → csid1 → vfe1_rdi0 → /dev/video3`，格式 `SGRBG10_1X10/4080x3072`，pixelformat `pgAA`。

## 3. 兼容性/前提：vk50 的 `LOCALVERSION` 一致性（本轮副产出）

vk50 churn 中内核 UTS 带了 `-vk50`（`7.2.0-debug-vk50-g5a70ade46a88`），但磁盘/ramdisk 里的相机模块
仍是 `7.2.0-debug-g5a70ade46a88`（不带）→ **vermagic 不匹配，模块根本加载不了**。
本轮用 `LOCALVERSION=-vk50` 重建全量模块（1513 个）、重打包相机闭包（20 个，vermagic 全 `…-vk50…`）、
重建相机 overlay ramdisk 与 vk50 boot 镜像后，相机才随内核正确加载。
**纪律**：任何 `-vkNN` 版本的内核，其模块必须同 `LOCALVERSION` 构建；
`package-camera-modules.sh` / `rootfs/build-camera-overlay.sh` / `scripts/iterate.sh mod`
均已按 `LOCALVERSION` 取 `kernelrelease`。

## 4. 已知坑（复现提醒）

- **镜像体积**：`build-camera-overlay.sh` 若不显式给 `BASE=`，会把上一版 camera ramdisk 又当基座
  叠加一次 → ramdisk 涨到 77 MiB、boot.img 101 MB（> boot_b 96 MiB 分区，无法 flash）。
  构建 camera 版务必 `BASE=out/rootfs-overlaid.cpio.gz.bak-vk48`（干净基座）。
  本轮先用了 101 MB 变体做 `fastboot boot`（零写盘可用），**尚未刷 boot_b**。
- 后摄与前摄要各用独立 csid/vfe，否则 `Resource busy`。
