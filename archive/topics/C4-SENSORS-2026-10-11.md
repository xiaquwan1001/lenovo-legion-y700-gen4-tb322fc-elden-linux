# C4 — Waydroid 传感器 HAL 注入（上机部署验证，U2 vk64，2026-10-11）

> 任务：`TASKS.md §2 C4` + `§5 Q14`。设备 U2 `HA2EXB0E`，b 槽 vk64，Waydroid（LineageOS 20 / Android 13）+ Phosh 会话。
> **结论：未通过。** 但**定位并修掉了 overlay 基础设施的两个真缺口**，HAL 能部署/加载/监听；**剩余阻塞 = 我们的 HAL 让框架 `SensorService` 卡死 → Android 卡 bootanim**。已回退到原可用状态。

## 0. 一句话结论

1. **overlay 机制此前根本没生效**：`/var/lib/waydroid/waydroid.cfg` 里 **`mount_overlays = False`**（历史为绕开缺模块而关），且**内核缺 `overlay`/`fuse` 模块**（部署模块目录又漏了 `fs/`）⇒ 部署脚本写的 `/var/lib/waydroid/overlay/vendor/...` 从没被挂上。
2. **已补齐**：重编部署 `overlay.ko`/`fuse.ko`（+之前的 `net/{llc,802,bridge,8021q}`），开 `mount_overlays=True` ⇒ **`/vendor` 变 overlayfs、定制 HAL（25280 B）生效、`waydroid.sensors.enabled=true`、HAL `sensors udp: listening on 0.0.0.0:52012`**。
3. **但框架卡死**：我们的 HAL 在位时，`SensorService` 起不来（`Service sensorservice didn't start`）→ `sys.boot_completed` 空、`bootanim` 一直 running。**改 `configureRpcThreadpool(1→4)` 后 `lshal` 不再 TIMED_OUT（alive），但框架仍卡**。
4. **单变量对照**：回到原版 stub HAL（`mount_overlays=False`）⇒ **`sensorservice` 正常注册、`sys.boot_completed=1`、`bootanim=stopped`** ⇒ **卡死与我们的 HAL 相关**，非 Waydroid 本身。
5. **已回退**：`mount_overlays = False`（原状态），容器 RUNNING、框架正常。补的模块保留（无害、且修了别的缺口）。

## 1. 证据链

**A. overlay 没生效**
```
$ cat /var/lib/waydroid/waydroid.cfg | grep mount_overlays
mount_overlays = False
$ waydroid shell -- ls -l /vendor/bin/hw/ | grep sensor
-rwxr-xr-x 1 root shell 16136 2026-09-27 ... android.hardware.sensors@1.0-service.waydroid   # 镜像原版，非我们 25280B 的
$ waydroid shell -- mount | grep ' on /vendor '
/dev/loop1 on /vendor type ext4 (ro,...)          # 纯 ext4，无 overlay
```

**B. 开 overlay 后失败的真因（缺模块）**
```
mount -t overlay -o ro,lowerdir=/var/lib/waydroid/overlay:/var/lib/waydroid/rootfs,... overlay /var/lib/waydroid/rootfs
mount: /var/lib/waydroid/rootfs: unknown filesystem type 'overlay'.
Mounting overlays failed. The feature has been disabled.
```
设备 `/lib/modules/<vk64>/` 无 `fs/` 子树；`modprobe overlay`/`fuse` 均 `not found`（`CONFIG_OVERLAY_FS=m`、`CONFIG_FUSE_FS=m`）。OpenRC `waydroid-container` 服务也因缺 `fuse` 报「Filesystem in Userspace support is not available」。
**修**：重编 `fs/overlayfs/overlay.ko`、`fs/fuse/fuse.ko`（`LOCALVERSION=-vk64`，vermagic 匹配，同 `net/` 那批）→ 部署 `$M/fs/...` + `depmod` → `modprobe overlay/fuse` rc=0。

**C. 开 overlay 成功（infra OK）**
```
$ waydroid shell -- mount | grep ' on /vendor '
overlay on /vendor type overlay (ro,relatime,lowerdir=/var/lib/waydroid/overlay/vendor:/var/lib/waydroid/rootfs/vendor,...)
$ waydroid shell -- ls -l /vendor/bin/hw/ | grep sensor
-rwxr-xr-x 1 root root 25280 2026-10-11 ... android.hardware.sensors@1.0-service.waydroid   # 我们的
$ waydroid shell -- getprop waydroid.sensors.enabled
true
$ waydroid shell -- logcat -d | grep 'sensors udp'
I android.hardware.sensors@1.0-service.waydroid: sensors udp: listening on 0.0.0.0:52012 (acc/gyr/mag/light/prox)
I android.hardware.sensors@1.0-service.waydroid: Waydroid Sensors HAL service ready.
```

**D. 框架卡死（阻塞点）**
```
$ waydroid shell -- getprop sys.boot_completed     # 空
$ waydroid shell -- getprop init.svc.bootanim      # running（一直）
$ waydroid shell -- service list | grep sensor
81  sensor_privacy: [android.hardware.ISensorPrivacyManager]
# 无 sensorservice
$ waydroid shell -- logcat -d | grep SensorService
D SensorService: nuSensorService starting...
I servicemanager: Could not find android.hardware.sensors.ISensors/default in the VINTF manifest.
I hwservicemanager: getTransport: Cannot find entry android.hardware.sensors@2.1::ISensors/default ...
I hwservicemanager: getTransport: Cannot find entry android.hardware.sensors@2.0::ISensors/default ...
I ServiceManager: Waiting for service 'sensorservice' on '/dev/binder'...   # 无限循环
```
我们的 HAL 第一次 `lshal` = **TIMED_OUT**（`interfaceChain` 无响应）⇒ 改 `service.cpp` 的 `configureRpcThreadpool(1, true)` → `(4, true)`（单 RPC 线程 + 阻塞 `poll` 会让其它调用超时），重编后 `lshal` = `Y ... PID 104`（不再超时）。**但仍卡 bootanim** ⇒ 还有第二个 HAL 层问题未定位。

**E. 单变量对照（回退原版）**
```
mount_overlays = False  →  HAL = 镜像原版 16136 B
$ waydroid shell -- service list | grep sensor
172  sensorservice: [android.gui.SensorServer]     # ← 有了
$ waydroid shell -- dumpsys sensorservice
No Sensors on the device        # stub 返回空，符合原设计
$ waydroid shell -- getprop sys.boot_completed
1                               # ← 框架完整启动
$ waydroid shell -- getprop init.svc.bootanim
stopped
```
