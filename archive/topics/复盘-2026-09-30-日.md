## 二、Linux 侧：熄屏无法唤醒 —— 根因定位与修复

### 排查链（每步都有硬证据）

1. 电源键事件**到内核**：`pwrkey.log`（`dd bs=24` 逐事件捕获 `/dev/input/event0`），
   `type=0001 code=0074`（EV_KEY/KEY_POWER）value 1/0 成对 ✅
2. phoc 正常持有输入（seatd→libinput 链路完好，keymap 编译成功），事件被 wlroots 消费 ✅
3. **会话里没有 gsd-power**：`gnome-session-binary: App 'org.gnome.SettingsDaemon.Power.desktop' exited with code 1`
4. strace 实锤：gsd-power 连会话总线 OK → **连 `/run/dbus/system_bus_socket` ENOENT** → "Failed to start" 退出
5. 起了系统 dbus 后，gsd-power 又卡 **D-Bus 激活**：`StartServiceByName org.freedesktop.UPower: Permission denied`
6. attach dbus-daemon strace 实锤：激活子进程以 **messagebus (uid 101)** 身份
   `execve("/usr/libexec/dbus-daemon-launch-helper") = -1 EACCES` ——
   helper 是 `root:root 4750`（应为 `root:messagebus` 4750；该文件日期 2026-03-20，曾被替换/打包丢权限）

### 根因（两层叠加）

- **系统总线没跑**（/init 不起 dbus）→ gsd-power 启动即退 → 无熄屏/唤醒/电源键管理
- **launch-helper 权限错**（root:root）→ 系统总线上 D-Bus 激活任何服务（upowerd/polkitd）都 EACCES

### 修复（已持久化）

```sh
# 1. 系统总线（rootfs 上持久；也写进了 start-desktop.sh）
mkdir -p /run/dbus && dbus-daemon --system

# 2. launch-helper 权限（Alpine 打包 bug，rootfs 重建会复发 → start-desktop.sh 里幂等修复）
chown root:messagebus /usr/libexec/dbus-daemon-launch-helper
chmod 4750 /usr/libexec/dbus-daemon-launch-helper
```

三件套起来：`gsd-power` + `upowerd` + `polkitd`（仅 logind 缺失的非致命警告）。
