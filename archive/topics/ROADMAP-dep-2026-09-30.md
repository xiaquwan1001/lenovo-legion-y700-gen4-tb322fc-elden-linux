> 本文回答一个问题：**哪些待办互相依赖、哪些其实互不相干**，从而排出正确顺序。

## 0. 一句话

**深色模式、缩放不依赖图形驱动**——它们已经在用户态跑通，只差你目视确认；
真正依赖内核图形驱动的是**夜灯（色温）**和**刷新率**。因此正确结构是：
先把「用户态桌面」收口（A 轨，基本已完成），再把「内核图形增强」单独立项（B 轨，独立、各自解锁一个功能）。

## 3. 依赖 DAG

```
F0 引导链/slot安全 ─┐
F1 持久root         ├─(已完成)─┐
F2 显示栈@120Hz      │           │
F3 会话基座          │           ├──► A 轨 用户态桌面（无内核依赖）
F4 网络+校时         │           │     A1 深色模式 ✅待目视
F5 内核迭代回路 ◆────┘           │     A2 缩放 2.5 待定值
                                 │     A3 电池/WiFi 图标 待目视
                                 │     A4 终端/输入法 ✅待目视
                                 │     A5 睡眠策略（无 suspend 暴露）
                                 │
F5 ◆─────────────────────────────┴──► B 轨 内核图形增强（F5 是唯一前置）
                                       B1  DSPP .gc  → 夜灯/色温/色彩管理   （小，低风险）
                                       B2  per-mode PLL/DCS → 刷新率选择    （大，可缓）
                                       B3  触摸唤醒（wlroots 活动路径）      （可选）

F5 ◆──────────────────────────────────► C 轨 其他独立驱动（互不相干）
                                        C1 音频 tplg（MI2S→aw88461）
                                        C2 TF 卡 sdhci-msm flush/cache
                                        C3 蓝牙配对 / 触觉
```

**唯一真正的前置**：B/C 轨都依赖 **F5（内核迭代回路）**——已就绪。
A 轨与 B/C 轨**零依赖**，可以随时收口。

**进度更新（2026-09-30 晚）**：B1 夜灯 ✅（vk14）；C3 振动马达 ✅（vk19，AW86937 CONT 模式，厂商 haptic.ko 反汇编移植，两个马达实测可震）。

## 5. 建议执行顺序

1. **A 轨收口**（你）：点亮屏幕确认三件事 —— Settings 是否深色、开关是否黄色、状态栏是否有 WiFi+电池图标；再给缩放定个值（`2` / `2.5` / `3.2` / `4`）。→ 冻结桌面基线，写进文档。
2. **B1 夜灯**（我做）：给 `sm8750_dspp_sblk` 补 `.gc = {.base=0x17c0,.len=0x40,.version=0x10008}`（老 SoC 同位置），重编 vk14 → `flash-b.sh` 上机 → 看 `Night Light` 是否变可用、gamma 是否生效。
   - 这是**最小的真·图形驱动改动**，一举验证「改内核→上机→验证」全线，且失败即回退旧内核。
   - ✅ **2026-09-30 完成**：vk14 上机，Night Light 面板出现调节、按钮可用；补丁存 `patches/0002-sm8750-dspp-gc-gamma.patch`。
3. **文档同步**（我做）：把散落在默认 profile 记忆里的最新成果（深色/缩放/NM/校时/colord/睡眠策略）并入本工作区 `INDEX.md` / `HANDOFF.md`，消除「文档落后于真机」的债务。
4. **再选**：B2（刷新率）或 C1（音频）或 C2（TF 卡）单独立项——三者互不依赖，按你的使用目标挑。

### 为什么是这个顺序
- A 轨不需要任何内核/驱动工作，先收口能立刻把设备变成「日常可用」，且零风险；
- B1 是 B 轨的最小切片，能低成本验证整条内核图形链路，为 B2 铺路；
- B2/C 都是深坑，必须单独立项、各自设时间盒，避免拖垮主线。
