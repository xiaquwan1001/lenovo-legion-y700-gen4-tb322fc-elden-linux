# Q24 机制取证轮（2026-10-12 第 7 轮）：GPU runtime-PM 否定 + 唤醒致死 4/4 复现 + 末帧 = dispcc 时钟使能

> 承接 `reports/q24-h1-result-20261012.md`（H1 否证）。原始数据：`logs/q24-mech1b-20261012-124825/`、`logs/q24-wake1-20261012-125140/`、`logs/q24-gpupm-20261012-125529/`、`logs/q24-mech2-20261012-125857/`。

## 0. 一句话

① **把 GPU `power/control` 钉成 `on`（不 runtime-suspend ⇒ 唤醒时无 GPU resume）后，`{camcc,cambist}` + 熄屏(存活) + **唤醒** 依旧静默硬复位** ⇒ GPU runtime-resume **不是**致死步骤；② 在 **L1FAIL 台架（面板未 init）**上，「配对 → 真熄屏（**存活**）→ 唤醒（**致死**）」成为**可重复**触发（4 次尝试 4 次死）；③ 唤醒致死的**最后一帧 trace** = **phoc 正在使能 `disp_cc_mdss_*`（MDP LUT / vsync / vsync_src）时钟**后即静止；④ 所有死亡现场的 RPMh 末段**共同点 = NoC/BCM（`0x500xx`）投票爆发**。

## 1. 实验与结果

| # | 台架 | 序列 | 结果 |
|---|---|---|---|
| A | L1FAIL（11:07 起） | 配对 → 熄屏 → hold 60 s | **存活**（`active=true, dpms=Off`） |
| B | 同 A | 继续**唤醒** | **死亡**（末帧：GPU 时钟树 `gpu_cc_*` 使能 + NoC 票 + `dev_pm_qos_update_request device=3d00000.gpu`） |
| C | 同台架类 | **GPU `power/control=on`** → 配对 → 熄屏（存活 30 s）→ **唤醒** | **仍然死亡（+87 s）** ⇒ **GPU resume 非必要步骤** |
| D | 同台架类，干净 trace 集 | 配对 → 熄屏（存活 30 s）→ 唤醒 | 15 s 窗口内仍活、随后**死亡**；末帧 = `phoc` 使能 `disp_cc_mdss_mdp_lut_clk / vsync_clk_src / vsync_clk` 后静止 |

- C 的 GPU 状态读数：`power/control: auto→on`、`runtime_status: suspended→active`（钉住生效）。
- D 的干净 trace 集 = `interconnect(m icc_set_bw) + clk + rpmh + devfreq`（**必须先把 `events/*/enable` 全部清零**，否则 `power/cpu_idle` 会淹没 trace：上一轮 3.8 M 行里 99.9% 是 cpu_idle）。

## 3. 判定

1. **GPU runtime-resume 被否定**（实验 C）——与 `PITFALLS #198` 里「phoc 卡在 `adreno_get_param→__pm_runtime_resume`」只是**同路径的表象**，不是根因。
2. **DT 空间已尽**（H1 否证）；驱动侧三路（FIX-1/2/3、E4a、去 `pd_ignore_unused`）此前已否证 ⇒ 下一步只能是**更底层的机制定位**或**改靶**。
3. 本轮**没有**改动任何内核/DTB（全部是运行时探针），因此**不引入构建身份伪影**。

## 4. 方法论收获（可复用）

- **日常 boot_b 本身就是可用台架**（L1FAIL 类配方）：无需 RAM 镜像、无需用户 POR 即可复现「配对 + 熄屏/唤醒」。面板 init 失败（`Failed to initialize panel`）但会话与仪表可用时，**熄屏不致死、唤醒才致死**；GOOD 台架则相反（熄屏即死）。
- **唤醒致死可在 15 s 判活窗口之后才发生**：D 轮 15 s 读数 `ALIVE=yes`，实际数十秒后死亡 ⇒ 判活窗口需 ≥60 s（或直接用 trace 流是否终止判死）。
- **trace 集必须先全清零**：`for d in events/*/; do echo 0 > $d/enable; done`；否则 `power/cpu_idle` 噪声量级 10⁶ 行，把有效帧埋掉。
- **陈旧 `trace_pipe` 读者会让新读者 `EBUSY`**：跑前 `pkill -f 'trace_pi[p]e'`（主机与设备都要），否则抓到空文件。
