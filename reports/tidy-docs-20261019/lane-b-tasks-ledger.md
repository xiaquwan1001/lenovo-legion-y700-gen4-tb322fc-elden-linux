## 0. 方法与两个必须先说的偏差

**测量方法（本 lane 可用工具只有 read/grep/ls/write，无 shell）**：用 rg 的字节级量词二分，
`^(?-u:.){N,}$` 计**字节**、`.{N,}` 计**码点**。标定：`TASKS/README.md:219`
（`### 2. 已知缺口的补救路径（G1 侧，简表）`）= 27 码点 / **55 字节**，`^(?-u:.){55}$` 命中、
`{56}$` 不命中 ⇒ 单位确认是 UTF-8 字节。**行长度精度 ±100 B**（步进二分未做穷尽），
凡标「≈」的区间宽度都写明。

**偏差一（重要，勿直接引用任务书里的两个数）**：任务书给「Q24 行 ≈7703 字节、Q28 行 ≈5091 字节」，
实测是 **Q24（L190）= 12 961 B**、**Q28（L192）∈ [8 200, 8 299] B**。任务书的数明显偏小
（大概量的是某一段而不是整行）。本报告**不依赖**任务书这两个数；
父 agent 可用下面这条命令一次复核全部绝对值：

```bash
LC_ALL=C awk '{printf "%d\t%d\t%s\n", NR, length($0), substr($0,1,40)}' TASKS/README.md \
  | sort -k2,2nr | head -25
```

**偏差二**：全文件 174 KB / 504 行 ⇒ 均值 353 B/行，但分布极偏（见 §2）。所以「§N 字节数」
本报告给的是**实测长行 + 短行折算**的估算（±10%），不是逐行求和；长行（≥1.5 KB）的值是实测区间。
