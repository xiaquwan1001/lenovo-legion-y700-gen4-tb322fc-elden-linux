## 1. 机制命中（H1 前提成立）


- 早期（0.30 s）的 8 次 `bias_en` 是 `cnt=0` 进入、写出后 **读回仍 0x0**（PHY 未上电，寄存器不保留）；
- **面板 bring-up（95.33 s）** 时 `phy_enable` 先把 `pll_enable_cnt` 预置 1 → 上游 7.3 形态在 `bias_en` 处**必然早退、`PLL_SYSTEM_MUXES` 永远保持 0x0**；E1 还原后本次**实测写入 0xc0 并读回 0xc0**。
- ⇒ 「上游 revert 掉的 bonded PLL 初始化写入在 elden（bonded 双 DSI）上确实被跳过」这一前提**由实测确立**（此前只有 lore + 静态 diff 旁证）。

## 4. 复现命令（含 UTS 钉法）

```bash
# 0) 源码 = clean-tree-73 @ ed6f232d10e3 + E1 提交
cd build/m1-upstream/clean-tree-73      # 提交 2fab129cd2（分支 m1-73/e1-pllfix 之上的工作区提交）
sed -i 's/^CONFIG_LOCALVERSION_AUTO=.*/CONFIG_LOCALVERSION_AUTO=n/' .config
sed -i 's/^CONFIG_LOCALVERSION="-debug"$/CONFIG_LOCALVERSION="-debug-ged6f232d10e3"/' .config
git tag -a v7.3-rc7 -m "temp UTS pin（构建后删除）"      # 只为此把 scm 后缀清空
rm -f include/config/kernel.release
make -s ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- kernelrelease   # == 7.3.0-rc7-debug-ged6f232d10e3
make -j16 ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- Image.gz dtbs  # 38 s（增量）
git tag -d v7.3-rc7                                   # 已删除（避免污染 describe）
# 1) 打包：kernel=新树，ramdisk/dtb 取自 73j 成品（单变量）

python3 tools/mkbootimg/mkbootimg.py --header_version 2 --os_version 15.0.0 --os_patch_level 2025-08 \
  --kernel $PWD/arch/arm64/boot/Image.gz --ramdisk /tmp/e1ref/ramdisk \
  --dtb $PWD/arch/arm64/boot/dts/qcom/sm8750-lenovo-elden.dtb \
  --cmdline 'console=ttyGS0,115200 console=tty0 loglevel=8 ignore_loglevel printk.devkmsg=on panic=15 clk_ignore_unused pd_ignore_unused arm-smmu.disable_bypass=0 elden_root=LABEL=linux17 androidboot.slot_suffix=_b elden_nocamera=1' \
  --base 0x00000000 --kernel_offset 0x00008000 --ramdisk_offset 0x01000000 --second_offset 0x00f00000 \
  --tags_offset 0x00000100 --dtb_offset 0x01f00000 --pagesize 4096 -o out/boot-elden-e1-pllfix.img
# 2) 上机
bash scripts/arm-console-run.sh out/boot-elden-e1-pllfix.img e1-pllfix 200
```
