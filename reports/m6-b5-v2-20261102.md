## §1 关键发现：v1 无法"重切"，只能"重做"

派工单预设"把 v1 剩余增量 cherry-pick 到公开 base"。实测**不成立**：

```
$ git -C build/b5-v2 show 6628e7d4c6:drivers/gpu/drm/msm/dsi/dsi_host.c | grep -c BROADCAST
0
$ git -C build/b5-v2 grep -c "msm_dsi_host_bonded\|is_sm8750\|bonded_cmd_failed" -- drivers/gpu/drm/msm/dsi/
(无命中)
```

v1 五枚补丁改的全部是**本地载荷**（`0f1fb1c9c1` = v7.3-rc7 + 一个 squashed 载荷提交）里的
bonded 命令路径；这条路径在公开树里一行都没有。因此 v2 的增量只能是**这条路径本身**，
这也与 2026-11-02 回信（`out/mail-20261102-b5/`）的口径一致：
"this series is the data half of proposing that path"。

附带发现（影响 review 预期）：v7.4-rc1 的 `dsi.xml` **删掉了**本路径要用的 10 处寄存器定义
（`BROADCAST_MASTER/WC_SEL/PACKET_TYPE`、`DMA_FIFO_CTRL`、`DMA_TRG_MUX`/`DMA_TRIGGER_EXT`、
`DMA_SCHEDULE_CTRL{,2}`、`VBIF_CTRL`、`CMD_DMA_CTRL1`）——7.3-rc7 的树里还有，
`diff build/vk151/.../dsi.xml build/b5-v2/.../dsi.xml` 可复现。v2 只补回用到的部分（21 行）。
