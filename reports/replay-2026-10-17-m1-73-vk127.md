## 1. 为什么不是「直接 rebase 旧 payload」

原 `build/m1-upstream/clean-tree-73` 已随换机丢失，且其 payload 的 squash 基点（`2e28b969d1`，父 = v7.2 tag）**对象不在本地浅克隆里**（`237a1c39e8df` MISSING）。
⇒ 重建方式改为：**用 USTC 镜像的 linux-7.2 源码包重建 pristine 基点**，再从下游树取「最终态」做三方合并：

1. `build/base-7.2` = `linux-7.2.tar.xz`（`mirrors.ustc.edu.cn`，6 s，sha256 `f9fef3d1…`）解包 + `git init` → 提交 `v72-base`。
2. 下游态来源**不能是 `v7.2-elden` tip（`ba28ec16f`）**：它**不含**运行期 12 个开发提交（温控分级 / WCD939x 音频 / aw86927 / psci / dpu GC / cdn …）。实测证据：用它出的板 DTB **140537 B**，缺 `passive0..3`、`audio-codec`、`wcd-capture-dai-link`、`splash_region`。
3. 改取 **`vk64`（`f595a1f5b`）树**（该线包含上述提交），再用**在机 DTB 指纹**收窄：
   指纹 = `pstore 0x200000` + `audio-codec` + `wcd-capture-dai-link` + `splash_region` + `passive0..3` + **cambist 双电源域（MMCX+MX）**。
   - `vk53` 差 3 项（`cdsp.mdt` 拆分 / `qcom,non-secure-domain` / 相机 rotation）；
   - `vk64` 命中全部，**但** cambist 是 Q24 的 H2 实验（只挂 MX）⇒ **回退成上游 parity**（回退后 DTB 与在机基线**同尺寸**）；
   - `vk83` 还带 Q24 FIX-1（只挂 MXC）⇒ 不取。
4. payload 提交 → `git cherry-pick` 到 7.3-rc7（三方合并保留 7.3 上游节点，如 coresight `tmc/replicator`）→ 再 `git am` 上游件 `0001-drm-msm-dsi-phy…`（M1 唯一可上游片）。

补丁序列已固化为 `patches/replay-2026-10-17/0001..0002`，并在干净 worktree 上 `git am` 验证 **2/2 OK**。

## 3. 唯一有意偏离基线：q6apm/q6prm 的 GPR 端口

在机 DTB 用上游 IID（`service@1`/`service@2`，`reg = GPR_APM_MODULE_IID/PRM`），本重放保留下游的 **`service@3`/`service@7`**（树内注释：SM8750 ADSP 固件只应答静态下游端口，其他源端口被静默丢弃）。
裁决：**保留 3/7**（vk64 日常线上音频实测可用；基线那版是否验过音频无记录）。若要完全对齐基线，改回上游两行即可，其余零差异。

## 6. 复现命令

```bash
# 1) 基线 7.2（一次性）
curl -O https://mirrors.ustc.edu.cn/kernel.org/linux/kernel/x7.x/linux-7.2.tar.xz  # 实际路径 v7.x
tar -xf linux-7.2.tar.xz && mv linux-7.2 build/base-7.2 && (cd build/base-7.2 && git init && git add -A && git commit -m pristine && git tag v72-base)

# 2) 7.3-rc7 worktree + 重放
git -C build/m3v2-7.3rc7 worktree add build/m1-73 24a19b953e --detach
cd build/m1-73 && git am ../../patches/replay-2026-10-17/0001-*.patch ../../patches/replay-2026-10-17/0002-*.patch

# 3) 日常 config（config-daily-c1 + C1 片段）+ 构建
cp ../../patches/config-daily-c1 .config
./scripts/kconfig/merge_config.sh -m .config ../../patches/fragment-c1-iprule.config ../../patches/fragment-c1-iprule6.config
make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- olddefconfig     # 之后必须核 CONFIG_ARCH_QCOM=y
make -j$(nproc) ARCH=arm64 CROSS_COMPILE="ccache aarch64-linux-gnu-" LOCALVERSION=-vk127 Image.gz dtbs modules

# 4) 打包（ramdisk 取自基线镜像）
python3 ../../scripts/mkbootimg.py --kernel arch/arm64/boot/Image.gz \
  --ramdisk ../../out/rootfs-vk127.cpio.gz \
  --dtb arch/arm64/boot/dts/qcom/sm8750-lenovo-elden.dtb \
  --cmdline "$(grep -o 'console=.*elden_nocamera=1' ../../out/boot-elden-vk127.manifest)" \
  --base 0x10000000 --kernel_offset 0x8000 --ramdisk_offset 0x1000000 \
  --second_offset 0xf00000 --tags_offset 0x100 --dtb_offset 0x1f00000 \
  --header_version 2 -o ../../out/boot-elden-vk127.img
```
