## §2 broken 根因（字节/行号证据）

**根因（已证）：v1 的提交信息里被塞进了一份手写的 diffstat，`git format-patch` 又自动追加了一份，
于是邮件正文出现两段 `---` 统计，且第一段紧贴 SoB、没有空行分隔 —— 这是「手写补丁/复制粘贴 diff」的特征，不是 git 产物。**

证据（`patches/upstream/m4-camss-2026-10-13/sent-20261027/0001-dt-bindings-regulator-add-Will-Semiconductor-WL2868C.patch`，`cat -A` 逐字节核对）：

| 行号 | 内容 | 说明 |
|---|---|---|
| 9 | `Signed-off-by: Qianhui Xu <...>$` | SoB 后**没有空行** |
| 10 | ` MAINTAINERS                                        \|    6 ++$` | 手写 stat **第 1 份**（前导空格，且列宽按 `+6` 对齐） |
| 11 | ` .../bindings/regulator/willsemi,wl2868c.yaml       \|   67 ++++...$` | 同上，**文件顺序 = MAINTAINERS 在前** |
| 12 | ` 2 files changed, 73 insertions(+)$` | |
| 13 | `---$` | 分隔符 |
| 14–16 | ` .../bindings/...yaml  \| 67 +++...` / ` MAINTAINERS \| 6 ++` / ` 2 files changed, 73 insertions(+)` | **手写 stat 第 2 份**（顺序相反、列宽不同） |
| 17 | ` create mode 100644 ...` | |
| 19 | `diff --git a/Documentation/...` | 真正的 diff 从这里才开始 |

复现验证（已证）：`git am` 该补丁到 pristine `24a19b953`，得到的 commit message 直接带着这段 stat ——
即 **stat 是被当成 commit message 正文提交进去的**，不是 send-email 弄坏的：

```
$ cd /tmp/amtest && git log -1 --format='%B' | cat -A | head -12
dt-bindings: regulator: add Will Semiconductor WL2868C PMIC$
$
Add DT binding for the Will Semiconductor WL2868C camera PMIC with$
seven programmable LDOs.$
$
Signed-off-by: Qianhui Xu <xiaqinghuan@mail.ustc.edu.cn>$
 MAINTAINERS                                        |    6 ++$
 .../bindings/regulator/willsemi,wl2868c.yaml       |   67 ++++++++++++++++++++$
 2 files changed, 73 insertions(+)$
$
```

补充：`git apply --check` 本身 **rc=0**（hunk 能套上，MAINTAINERS 偏移 −12 行），所以问题**只在提交信息**，
不在 diff 内容 —— 这也是为什么本地 checkpatch 当时报 0E/0W/0C 却没发现：checkpatch 不校验 stat 段。

**结论：broken = commit message 内嵌手写 diffstat（第 10–12 行），与 format-patch 自动生成的那份（第 14–17 行）重复。**
