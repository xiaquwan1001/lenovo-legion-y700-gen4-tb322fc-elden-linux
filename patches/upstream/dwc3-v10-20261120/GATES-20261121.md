## 2. 门形状的两个坑（本轮再次确认，判据见 `PITFALLS #696` 与 README §4）

1. **`DT_SCHEMA_FILES` 对公共片段恒空转**：`scripts/Makefile.dtbs` 传 `dt-validate -l`，只保留
   `$id` 命中**且自己 `select` 到节点**的 schema；`snps,dwc3-common.yaml` 是没有 `select:` 的
   片段 ⇒ 零诊断的「假绿」。本轮 G5 用**不带** `DT_SCHEMA_FILES` 的形状，并加 baseline 对照。
2. **`cmd_dtb_check` 末尾 `|| true`** ⇒ rc 恒 0，判绿只能数输出里的 `^arch/.*dtb:` 诊断行。
   本轮记法 = `DTC [C]` 条数 + 诊断起始行数 + 其中 USB/dwc3 相关行数。
