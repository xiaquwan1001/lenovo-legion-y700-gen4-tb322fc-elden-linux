# #745 · 判据门的「≥N 字说明」挡不住模板化用途句：批量回填能刷绿而零信息

**结论**：`scripts/reports-orphan-check.py` 的反作弊只查「去掉路径后剩 ≥8 个非空白字符」，于是一次批量回填把
165 行全写成同一句 `… 记录该次主题核验的结论与证据。` —— 字数够、门变绿、但一行信息都没多。
**字数阈值不是信息量阈值**，凡「补指针/补说明」类门都会被这一手绕过。

**实测（2026-11-27，本仓）**：

| 阶段 | all 刻度孤儿 | 说明 |
|---|---|---|
| 回填前 | 165 / 706 | 真孤儿 |
| 子代理回填后（同一句模板） | **0 / 707 门绿** | ← 假绿：用途句 165 行逐字相同 |
| 加固判据后（同一批语料重扫） | **32** 现形 | 说明加固有效，但只能抓「整句完全相同」 |
| 逐篇用报告自身 H1 标题重写 + 去模板尾巴 | **0 / 710** | 真绿（每行用途即该报告标题，唯一且可检索） |

**加固内容（已落 `scripts/reports-orphan-check.py`，selftest 15 条断言 FAIL=0）**：
① 空用途句黑名单（`GENERIC_PURPOSES`：见报告/同上/待补/那条模板句…）；
② 同一用途句跨语料复用 >`PURPOSE_DUP_MAX`(3) 次 ⇒ 整行作废；
③ 一行点名 >4 个报告时，必须**另有一段 ≥40 字真说明**（否则 `too-many-names`）——之前用 `\S*\.md` 做路径分词，
会把「`a.md`、`b.md`」当成**一个** token，长表格行因此被误判合规；
④ token 正则收紧为 `[A-Za-z0-9_./-]*\.md`（不再吞 CJK/反引号）。

**同类门自查清单**（任何「补说明/补指针/补引用」门都适用）：
- 阴性对照里必须有「字数够但整句相同」与「整句相同但字数够 ×N 行」两种反例；
- 复用上限与黑名单都要在 selftest 里各有一条断言（本轮 15 条里 2 条就是它们）；
- 门绿之后抽 3 行人工读：**读不出这篇报告讲什么 = 假绿**。

**可复查**：`scripts/reports-orphan-check.py --selftest`（15 条断言）、`--check --no-list`（rc=0，710/710）；
`reports/reports-index-backfill-20261127.md`（回填过程与三刻度数字）、`TASKS/sessions/2026-11-27-reports索引-*.md`（10 篇主题索引）。
